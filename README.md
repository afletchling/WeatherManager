# Overview

WeatherManager is a Java 8 applet designed for storing data coming from the OpenWeatherAPI. This software was made for me to learn how to properly manage and design project structure alongside adding comments to code for other people to look at and understand.

I used abstract classes, dependencies, conditionals, loops, and methods to write the project.

# Development Environment

IntelliJ IDEA

org.gson for parsing out JSON into classes
